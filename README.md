# Tree Explorer

An interactive 3D tree in the browser for learning tree biology. Drag to look around; click a label to fly to the leaves, trunk or roots.

```sh
npm install
npm run dev
```

Planned stages:

1. The tree, swaying in the wind, with three stops: leaves, trunk, roots.
2. Trunk cross-section: bark, phloem, cambium, sapwood, heartwood.
3. Water transport from root to leaf.
4. Roots, root hairs, fungi and rock.
5. A plant cell that comes apart into its organelles.
